# KRUGER — Personal AI Assistant

**Project PEGASUS**

KRUGER is a personal desktop AI assistant built as a learning project using Python. It supports voice commands, wake-word activation, application control, window focusing, reminders, system information, and other desktop automation features.

## Features

- Wake word: **“Kruger”**
- Voice mode with sleep and exit commands
- Open, close, and focus desktop applications
- Chrome profile launch support
- Time, weather, and system information
- Reminder and memory modules
- Command splitting (e.g., “open chrome and open vs code”)
- Confidence-based execution
- Modular skill architecture

## Technologies

- Python
- Whisper speech recognition
- pyttsx3 text-to-speech
- psutil
- pygetwindow / pywin32
- Git & GitHub
